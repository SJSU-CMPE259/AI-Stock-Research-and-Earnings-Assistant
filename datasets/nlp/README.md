# NLP annotation queue

`annotation_queue.csv` starts with three sourced NVIDIA filing excerpts and blank
human labels. It is generated by `notebooks/p2_analysis_nlp.ipynb`; reruns preserve
human fields and older rows. It is not a completed or representative evaluation set.

Follow `docs/nlp_annotation_guide.md`. Add real passages using the schema in
`ACSESS/finsight/backend/tests/fixtures/nlp/passages.json`, then rerun the notebook.
Keep raw filings and generated analysis output under ignored `data/`; track
reviewed annotations here. Avoid committing confidential or personal data.
